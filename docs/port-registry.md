# ポート台帳（写し）

正本は Notion「ポート管理」データベース。変更するときは両方を更新する。

- 予約レンジ: **22500-22599**（2026-10-08 採番）
- 定義: [tts-api-containers/docker-compose.yml](../tts-api-containers/docker-compose.yml)

| ポート | サービス | コンテナ内部 | 既定バインド | 用途 |
|---|---|---|---|---|
| 22500 | api | 8080 | 127.0.0.1（固定） | OpenAI 互換の TTS API。エンジンへモデル名で振り分ける |
| 22501 | chat | 3000 | 127.0.0.1（固定） | 開発用の動作確認画面（profile `dev` のみ） |
| —（非公開） | engine-irodori | 8000 | ホスト公開なし | Irodori-TTS エンジン。compose 内のネットワークからのみ到達できる |
| 22502-22599 | — | — | — | 予備 |

- ホスト公開ポートは `.env` の `API_HOST_PORT` / `CHAT_HOST_PORT` で上書きできるが、22500-22599 の範囲内に限る。
- api は認証を持たないので、ホスト外へ公開しない。外へ出すときは認証を足してから。
- エンジンを足すときもホストへは公開せず、api の `ENGINES` に登録する。
